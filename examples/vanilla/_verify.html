The component library.

A small, opinionated set of primitives built on the editorial system — warm paper, one amber action per surface, hairlines instead of card shadows, mono small-caps for labels. Every component below is rendered straight from the published editorial-ui stylesheet.

Links

Inline links sit on a soft underline; standalone links lead with the arrow.

The library borrows the paper-and-ink palette from the editorial popup, extends it with a small status set, and reserves amber emphasis for a single hero action. Items can be permanently destructive as well.
